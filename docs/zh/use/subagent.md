# 子代理 {#agent-handsoff-与-subagent}

子代理让内置 AI 把任务交给具有独立上下文的后台 Agent，同时继续主会话。无需安装额外插件。

## 启用子代理

进入对应配置档的 **配置文件 → AI → 能力 → 子代理**，启用后即可使用通用子代理。并发数默认 3，超时默认 600 秒，包含排队时间。

![子代理能力设置](images/subagent-settings-zh.png)

## 配置专用 Agent

1. 点击 **配置专用 Agent**，然后点击 **新建 Agent**。
2. 选择 AstrBot 运行时，填写名称和描述。描述帮助主 Agent 判断何时委派任务。
3. 选择人格和聊天模型，留空则跟随主 Agent。
4. 保存并关闭弹窗，在 **专用 Agent 配置** 中勾选该 Agent。

**子代理用哪个模型**：选了聊天模型的专用 Agent 使用该模型；留空的专用 Agent 和通用子代理使用派出它的这次请求所用的模型（例如 ChatUI 里为这条消息选择的模型），没有时使用会话默认模型。主 Agent 能看到每个专用 Agent 对应的模型和所有可用的聊天模型；用户点名要某个模型时（如「派 3 个 luna」），如果已有使用该模型的专用 Agent 就直接用它；没有的话，主 Agent 在 `spawn_agent` 中传入该模型的 `provider_id`，AstrBot 会自动新建一个使用该模型、没有人格的专用 Agent（名称如「gpt-6-luna worker」，描述注明是自动创建的），并在当前会话所用的配置文件中勾选它。同时派出多个时只会新建一个；之后再要这个模型会直接复用。只能使用已经启用的聊天模型，不存在的 ID 会被拒绝并列出可用的 ID；不会新建模型提供商或凭据。如果已有一个使用该模型、没有人格的专用 Agent（无论是手动还是自动创建的），会优先复用它而不是再建一个。主 Agent 会在回复中说明新建了专用 Agent；它也会出现在 ChatUI **设置 → 智能体 → 子代理** 和配置页的专用 Agent 列表中，可以在 **配置专用 Agent** 中修改或删除。主 Agent 若把聊天模型的 ID 误填进 `config_id`，会按 `provider_id` 处理；空的 `config_id`、`provider_id` 视为未填写。

![子代理管理页面](images/subagent-create-zh.png)

![新建 Agent 表单](images/subagent-edit-zh.png)

所选人格提供提示词、工具和技能，权限受父 Agent 可委派的能力限制。步数上限、工具超时等其他设置在创建会话时继承主 Agent。配置修改适用于新会话。

点击卡片即可编辑 Agent。删除前，需要先解除配置档或其他 Agent 配置对它的引用。不可用运行时的配置仍会保留，但不能启动新会话。

## 委派任务与追加指令

可以对主 Agent 说：“让子代理审阅这份报告，我们继续讨论下一步。”主 Agent 通过以下工具管理任务：

| 工具 | 用途 |
| --- | --- |
| `spawn_agent` | 启动后台任务。 |
| `list_agents` | 查看任务状态。 |
| `wait_agent` | 等待结果。 |
| `get_agent_result` | 读取结果。 |
| `send_message` | 向已有 Agent 追加指令。 |
| `cancel_agent` | 停止任务。 |

配置弹窗只管理保存的 Agent 配置。查看或停止运行中的任务，可以让主 Agent 操作；在 ChatUI 中也可以打开工作台的 **会话** 页，在 **子代理** 一节查看本对话的子代理：

- 每行显示「模型 · 思考程度 · 任务简称」、正在做什么（如正在运行代码、正在编辑文件）和已运行时间。思考程度只在该子代理所用的模型提供商配置里设置了时显示。
- 运行中的子代理行尾有方块按钮，用于停止它和它排队的指令。停止后子代理会话仍保留，主 Agent 之后仍可以向它发送指令。
- 展开一行可以看到完整名称、模型提供商、人格、最近一次请求的上下文、可用工具、任务和结果，以及累计用量（输入、缓存命中和输出，按提供商上报的数据相加；有请求没有上报时标注「部分请求未上报」，实际用量更高）。
- 派出子代理的回复下方，每个子代理有一个小标签（如「haiku 正在运行代码」），点击可在 **会话** 页中定位到它。

子代理不能继续创建子代理。

委派输入支持文本、图片和文件引用，不会自动附带原用户消息中的图片。追加指令会沿用子代理的历史；内置运行时中的追加图片和文件以文本引用传递。

## 重启与会话行为

同一会话内的用户共享子代理。结果始终返回原父会话，切换会话不会改变投递目标。父会话已删除或停止时不会唤醒。

重启后，排队中和未完成的任务会标记为已中断，不会自动重放。查看状态后，可以让主 Agent 发送新指令，在原子代理会话中继续。

## 升级说明

原侧边栏的 **子代理编排 / 子代理管理** 已移至 **配置文件 → AI → 能力 → 子代理 → 配置专用 Agent**。旧地址 `/subagent` 仍可访问。

原有全局设置和专家配置会自动迁移，已有会话与历史会保留。

API 调用方应将 `/api/v1/subagents/config` 和 `/api/subagent/config` 替换为 `/api/v1/agent-configs` 与 `/api/v1/agent-configs/{config_id}`。使用 `/api/v1/agent-runtimes` 查询运行时及默认配置。这些接口需要 `config` 权限，参见 [OpenAPI 权限](../dev/openapi-scopes.md)。

插件接入请参见[运行 Agent](../dev/star/guides/ai/agent.md#run-session-agent)和 [runtime 事件](../dev/star/guides/ai/agent.md#runtime-events)。
